# Clinical Blood Compatibility & Eligibility Matrix (docs/research)

## Project Name: Blood Donation Network (BDN)
**Document Version:** 1.0.0  
**Medical References:** World Health Organization (WHO) & American Red Cross Standards  

---

## 1. Packed Red Blood Cell (PRBC) Compatibility Matrix

In packed red blood cell transfusions, recipient antibodies react against donor ABO and Rh surface antigens.

| Recipient Blood Group | Compatible Donor Blood Groups (Can Receive From) |
| :--- | :--- |
| **O Negative (O-)** | **O-** *(Universal Red Cell Donor)* |
| **O Positive (O+)** | **O-**, **O+** |
| **A Negative (A-)** | **O-**, **A-** |
| **A Positive (A+)** | **O-**, **O+**, **A-**, **A+** |
| **B Negative (B-)** | **O-**, **B-** |
| **B Positive (B+)** | **O-**, **O+**, **B-**, **B+** |
| **AB Negative (AB-)** | **O-**, **A-**, **B-**, **AB-** |
| **AB Positive (AB+)** | **O-**, **O+**, **A-**, **A+**, **B-**, **B+**, **AB-**, **AB+** *(Universal Recipient)* |

---

## 2. Fresh Frozen Plasma (FFP) Compatibility Matrix

In plasma transfusions, compatibility rules are **reversed** because plasma contains antibodies against absent red cell antigens.

| Recipient Blood Group | Compatible Plasma Donor Blood Groups |
| :--- | :--- |
| **O** | **O**, **A**, **B**, **AB** |
| **A** | **A**, **AB** |
| **B** | **B**, **AB** |
| **AB** | **AB** *(Universal Plasma Donor)* |

---

## 3. Clinical Donation Cooldown Intervals

| Donation Component Type | Minimum Mandatory Cooldown Between Donations |
| :--- | :--- |
| **Whole Blood** | **56 calendar days** (8 weeks) |
| **Double Red Cells (Apheresis)** | **112 calendar days** (16 weeks) |
| **Platelets (Pheresis)** | **14 calendar days** (max 24 times/year) |
| **Plasma (Pheresis)** | **28 calendar days** |
