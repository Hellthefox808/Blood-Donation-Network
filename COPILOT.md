# GitHub Copilot Instructions: Blood Donation Network (BDN)

## Code Generation Conventions
- **TypeScript:** Strict mode enabled. Prefer explicit return types on functions.
- **Backend:** Express route handlers delegate to services. Services handle Prisma queries.
- **Frontend:** Next.js 14 App Router client components specify `"use client"`. Use Tailwind CSS and Lucide icons.
- **Naming Conventions:** `kebab-case.ts` for files, `PascalCase.tsx` for React components, `camelCase` for variables/methods, `UPPER_SNAKE_CASE` for constants.
